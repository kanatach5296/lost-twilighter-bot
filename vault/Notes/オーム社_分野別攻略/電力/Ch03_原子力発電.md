## ⚡ 核心要点・公式・出題解法エッセンス

### 1. 核分裂反応と構成要素
- 燃料: $^{235}\text{U}$（低濃縮 $3 \sim 5\%$）
- 減速材: 高速中性子を熱中性子へ減速（軽水）
- 冷却材: 熱を取り出し蒸気へ輸送（軽水）
- 制御棒: 中性子吸収（炭化ホウ素、ハフニウム）

### 2. BWR（沸騰水型）とPWR（加圧水型）の完全比較
| 項目 | BWR（沸騰水型） | PWR（加圧水型） |
| :--- | :--- | :--- |
| **サイクル** | 直接サイクル（1系統） | 間接サイクル（1次系＋2次系） |
| **沸騰** | 圧力容器内で直接沸騰 | 加圧器で高圧（約15MPa）に保ち沸騰阻止 |
| **蒸気発生器** | 不要 | **必須（熱交換器）** |
| **タービンの放射能** | あり（遮蔽必要） | **なし（隔離）** |
| **制御棒挿入** | 下から上へ挿入 | **上から重力落下で挿入** |
| **国内採用** | 東日本（東電・東北電） | 西日本（関電・九電） |

### 3. 固有の安全性（負の反応度フィードバック）
- **ボイド効果**: 出力増 $\to$ 気泡（ボイド）増 $\to$ 減速材密度低下 $\to$ 熱中性子減 $\to$ 出力低下。
- **ドップラー効果**: 燃料温度上昇 $\to$ 共鳴吸収増 $\to$ 反応度抑制。
