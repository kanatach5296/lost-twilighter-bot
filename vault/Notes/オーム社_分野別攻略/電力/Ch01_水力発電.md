## ⚡ 核心要点・公式・出題解法エッセンス

### 1. 理論水力と発電出力
- 理論水力 $P_0 = 9.8 Q H \ [\text{kW}]$、発電端出力 $P = 9.8 Q H \eta_t \eta_g \ [\text{kW}]$
- 落差 $H$ と流量 $Q$ の関係、有効落差 $H = H_0 - h_l$（管路摩擦損失水頭 $h_l \propto Q^2$）

### 2. ベルヌーイの定理
$$h + \frac{p}{\rho g} + \frac{v^2}{2g} = \text{一定}$$
- 位置水頭 $h$、圧力水頭 $\frac{p}{\rho g}$、速度水頭 $\frac{v^2}{2g}$

### 3. 水車の種類と選定
- **ペルトン水車（衝撃水車）**: 高落差・小流量。ニードル弁とデフレクタ。
- **フランシス水車（反動水車）**: 中落差・中流量。最も普及。案内羽根（ガイドベーン）で流量制御。
- **カプラン水車（反動水車）**: 低落差・大流量。可動翼で部分負荷効率良好。
- 比速度 $n_s = n \frac{P^{1/2}}{H^{5/4}}$

### 4. 揚水発電の総合効率
$$\eta = \eta_t \eta_g \times \eta_p \eta_m \times \frac{H_g}{H_p} \approx 70 \sim 75\%$$
- ピーク時発電・オフピーク時揚水。揚水動力 $P_p = \frac{9.8 Q H_p}{\eta_p \eta_m}$。
