## ⚡ 核心要点・公式・出題解法エッセンス

### 1. すべり $s$ と同期速度 $N_s$
- **同期速度**: $N_s = \frac{120 f}{p} \ [\text{min}^{-1}]$
- **すべり $s$**: $s = \frac{N_s - N}{N_s}$ （静止時 $s=1$、同期運転時 $s=0$、電動機 $0 < s < 1$、発電機 $s < 0$、制動 $s > 1$）
- **二次誘導起電力・周波数**: $E_2 = s E_{20}$、$f_2 = s f_1$

### 2. パワーフロー（電力の流れ比率 ★最頻出）
$$P_2 : P_{c2} : P_m = 1 : s : (1 - s)$$
- 二次銅損: $P_{c2} = s P_2$、機械出力: $P_m = (1 - s) P_2$
- 内部機械効率: $\frac{P_m}{P_2} = 1 - s$、トルク: $T = \frac{P_2}{\omega_s} = \frac{P_m}{\omega}$

### 3. トルク特性と比例推移
- **トルクの電圧依存性**: トルクは**端子電圧の2乗に比例**（$T \propto V_1^2$）。
- **比例推移（巻線形）**: 二次回路に抵抗を挿入すると、**最大トルクの大きさは一定のまま**、最大トルクすべり $s_m$ が抵抗値に比例して増大（$\frac{r_2}{s_m} = \frac{r_2 + R_{\text{ext}}}{s_m'} = \text{一定}$）。始動電流を抑えつつ始動トルクを大幅増大。

### 4. 始動法と速度制御
- **かご形始動法**:
  - [[スターデルタ（Y-Δ）始動法]]: 相電圧 $1/\sqrt{3}$ 倍、**始動電流・始動トルクともに $1/3$ 倍**。
  - 始動補償器法（コンドルファ法）: 単巻変圧器で減電圧。
- **インバータ制御**: $V/f = \text{一定}$ 制御により、磁束飽和を防ぎ最大トルクを保ったまま無段階変速。
