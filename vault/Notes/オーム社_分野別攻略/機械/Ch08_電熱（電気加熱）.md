## ⚡ 核心要点・公式・出題解法エッセンス

### 1. 熱量計算の基礎
- **電力量と熱量換算**: $1\,\text{kW}\cdot\text{h} = 3600\,\text{kJ} = 860\,\text{kcal}$
- **所要熱量 $Q$**:
  $$Q = m c \Delta T + m L \quad [\text{kJ}]$$
  （質量 $m \ [\text{kg}]$、比熱 $c \ [\text{kJ/(kg}\cdot\text{K)}]$、潜熱 $L \ [\text{kJ/kg}]$）
- **電熱器の所要電力 $P$**:
  $$P = \frac{Q}{3600 \, t \, \eta} \quad [\text{kW}] \quad (t: \text{時間}[\text{h}], \ \eta: \text{熱効率})$$

### 2. 熱移動の3様式
1. **熱伝導**: フーリエの法則 $Q = \lambda \frac{A}{d} (T_1 - T_2) t$
2. **熱放射（ステファン・ボルツマンの法則）**:
   $$J = \varepsilon \sigma (T_1^4 - T_2^4) \quad [\text{W/m}^2]$$
   （放射熱流束は絶対温度の**4乗に比例**）
3. **熱対流**: ニュートンの冷却の法則 $Q = \alpha A (T_w - T_f) t$

### 3. 電気加熱方式の分類
- **抵抗加熱**: 直接式（被加熱物に通電）と間接式（発熱体からの伝熱）。
- **[[誘導加熱]]**: 導電体を交番磁束内に置き、渦電流損＋ヒステリシス損で加熱。**表皮深さ $\delta = \sqrt{\frac{2}{\omega \mu \sigma}}$**（高周波ほど表面加熱）。
- **誘電加熱**: 絶縁物（誘電体）を高周波電界内に置き、誘電損（$P = 2\pi f C V^2 \tan\delta$）で内部自己発熱（電子レンジ、木材乾燥）。
- **アーク加熱**: アーク放電の超高温（数千度）利用（電気製鋼炉）。
