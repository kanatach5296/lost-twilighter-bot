# 電磁鋼板のJIS規格記号と鉄損計算

電磁鋼板（帯）のJIS規格（**JIS C 2552**：無方向性、**JIS C 2553**：方向性）における種類記号の構成と、任意の磁束密度における鉄損の計算公式・演習プロセスのまとめ。

---

## 1. JIS規格記号の読み方（形式：`□□ - □□□`）

例：`50A310`、`30G140`

```
  5 0      A      3 1 0
 └──┬──┘   │     └───┬───┘
    │      │         └─ ③ 単位重量あたりの鉄損測定値 [W/kg] × 100
    │      └─────────── ② 種類名（材料区分）
    └────────────────── ① 公称厚さ [mm] × 100
```

1. **先頭の2桁 (`□□`)**: 板厚（公称厚さ） $[\text{mm}] \times 100$
   - 例：`50` $\implies 0.50 \ \text{mm}$、`30` $\implies 0.30 \ \text{mm}$、`35` $\implies 0.35 \ \text{mm}$
2. **アルファベット記号 (`□`)**: 種類記号
   - **A** : **無方向性**電磁鋼帯（JIS C 2552）
   - **G** : 方向性電磁鋼帯・**普通**（高磁束密度材料）（JIS C 2553）
   - **P** : 方向性電磁鋼帯・**高磁束密度材料**（低鉄損）（JIS C 2553）
   - **R** : 方向性電磁鋼帯・**磁気ドメイン制御材**（レーザー照射等）（JIS C 2553）
3. **末尾の3桁 (`□□□`)**: 単位重量あたりの**鉄損の測定値** $[\text{W/kg}] \times 100$
   - 例：`310` $\implies 3.10 \ \text{W/kg}$、`140` $\implies 1.40 \ \text{W/kg}$

---

## 2. 任意磁束密度 $B$ における鉄損計算公式

鉄損は周波数が一定であれば、磁束密度 $B$ の**2乗に比例**します。

### ① 無方向性電磁鋼帯（JIS C 2552）
- 測定条件：周波数 $f = 50 \ \text{Hz}$、板厚 $d = 0.5 \ \text{mm}$、磁束密度 $B = \mathbf{1.5 \ \text{T}}$ における測定値を $w_5 \ [\text{W/kg}]$ とする。
- 任意磁束密度 $B \ [\text{T}]$ での鉄損式：
  $$w = w_5 \left(\frac{B}{1.5}\right)^2 \quad [\text{W/kg}]$$

### ② 方向性電磁鋼帯（JIS C 2553）
- 測定条件：周波数 $f = 50 \ \text{Hz}$、磁束密度 $B = \mathbf{1.7 \ \text{T}}$ における測定値を $w_7 \ [\text{W/kg}]$ とする。
- 任意磁束密度 $B \ [\text{T}]$ での鉄損式：
  $$w = w_7 \left(\frac{B}{1.7}\right)^2 \quad [\text{W/kg}]$$

---

## 3. 代表演習問題と解答プロセス

### 【問9】50A310 材料、磁束密度 $B = 1.2 \ \text{T}$ の鉄損 $w_{01.2}$
1. **記号解読**:
   - `50A310` $\implies$ 無方向性電磁鋼帯（A）、$w_5 = \frac{310}{100} = 3.10 \ \text{W/kg}$
2. **公式適用**:
   $$w_{01.2} = w_5 \left(\frac{B}{1.5}\right)^2 = 3.10 \times \left(\frac{1.2}{1.5}\right)^2 = 3.10 \times (0.8)^2 = 3.10 \times 0.64 = 1.984 \quad [\text{W/kg}]$$
3. **解答**: **$w_{01.2} = 1.98 \ \text{W/kg}$**（または $1.984 \ \text{W/kg}$）

---

### 【問10】30G140 材料、磁束密度 $B = 1.8 \ \text{T}$、重量 $5 \ \text{kg}$ の全鉄損 $W_F$
1. **記号解読**:
   - `30G140` $\implies$ 方向性電磁鋼帯（G）、$w_7 = \frac{140}{100} = 1.40 \ \text{W/kg}$
2. **単位重量あたり鉄損 $w$ の算出**:
   $$w = w_7 \left(\frac{B}{1.7}\right)^2 = 1.40 \times \left(\frac{1.8}{1.7}\right)^2 \approx 1.40 \times 1.121107 \approx 1.5695 \quad [\text{W/kg}]$$
3. **全鉄損 $W_F$ の算出（重量 $G_F = 5 \ \text{kg}$）**:
   $$W_F = w \times G_F = 1.5695 \times 5 = 7.8475 \approx 7.85 \quad [\text{W}]$$
4. **解答**: **$W_F = 7.85 \ \text{W}$**
