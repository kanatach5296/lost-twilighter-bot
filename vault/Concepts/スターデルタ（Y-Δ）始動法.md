# スターデルタ（Y-Δ）始動法

かご形三相誘導電動機において、始動電流を抑制するために用いられる代表的な減電圧始動法。通常運転時は $\Delta$（デルタ）結線で使用する巻線を、始動時のみ $\text{Y}$（スター）結線に切り替えます。

## 諸特性の比較（全電圧始動比）

| 項目 | スター結線始動時（全電圧 $\Delta$ 結線比） |
| :--- | :--- |
| **巻線相電圧** | **$\dfrac{1}{\sqrt{3}}$ 倍** |
| **始動線電流** | **$\dfrac{1}{3}$ 倍** |
| **始動トルク** | **$\dfrac{1}{3}$ 倍** |

> [!IMPORTANT] 試験頻出ポイント
> - 相電圧が $\frac{1}{\sqrt{3}}$ 倍になることで相電流が $\frac{1}{\sqrt{3}}$ 倍になり、さらに線電流への変換（$\sqrt{3}$ 倍から 1 倍へ）によって、始動線電流は **$\frac{1}{3}$** に抑えられます。
> - トルクは印加電圧の **2乗に比例** するため、始動トルクも同様に **$\frac{1}{3}$** に低下します。そのため、軽負荷状態で始動する必要があります。
