# 送電線のフェランチ効果と自己励磁現象

長距離送電線路や地中ケーブル系統において、夜間などの軽負荷・無負荷時に大きな対地静電容量（進相充電電流）によって引き起こされる電圧異常上昇現象（**フェランチ効果**）と発電機の**自己励磁現象**。

---

## 1. フェランチ効果（Ferranti Effect）

### ① 発生メカニズム
長距離架空送電線や高圧ケーブル線路には大きな対地静電容量 $C$ が存在します。
軽負荷・無負荷時、線路には進み位相の充電電流 $I_c = \omega C V$ が流れます。
この進み電流が送電線のインダクタンス $L$（リアクタンス $X_L$）を流れると、リアクタンスによる電圧降下が電源電圧と同相（加算方向）に現れるため、**受電端電圧 $V_r$ が送電端電圧 $V_s$ よりも高くなる現象**が生じます。

$$V_r \approx V_s + \omega^2 L C V_s = V_s (1 + \omega^2 L C) > V_s$$

### ② 防止・抑制対策
- **分路リアクトル（Shunt Reactor）の投入**:
  変電所に分路リアクトルを並列接続し、遅れ無効電力を消費させて進み充電電流を相殺・吸収する。

---

## 2. 同期発電機の自己励磁現象（Self-Excitation）

### ① 発生メカニズム
無負荷の長距離送電線に同期発電機を接続して充電を開始した際、進相電流 $I_c$ が電機子巻線に流れると、同期機の**電機子反作用が進み電流によって「増磁作用（界磁を強める作用）」**として働きます。
この結果、界磁電流を絞っても端子電圧が自己増殖的に上昇し、鉄心の磁気飽和点まで電圧が跳ね上がって制御不能になる現象を自己励磁現象と呼びます。

### ② 発生条件と対策
- **発生条件**: 発電機の同期リアクタンス $X_s$（または短絡比 $K_s$ の逆数）が、送電線の充電リアクタンス $X_c = \frac{1}{\omega C}$ よりも大きい（$X_s > X_c$）場合に発生する。
- **対策**:
  1. 短絡比 $K_s$ の大きい同期機（$X_s$ の小さい鉄機械）を採用する。
  2. 系統に分路リアクトルを投入して充電容量を減らす。
  3. 発電機の界磁制御（速応励磁装置、負励磁制御）を適用する。
