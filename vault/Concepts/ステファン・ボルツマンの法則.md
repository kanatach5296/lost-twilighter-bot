# ステファン・ボルツマンの法則

黒体（理想的な放射体）の表面から単位面積あたりに放射される全放射熱流束 $J$ は、その物体の熱力学的温度（絶対温度 $T$）の**4乗に比例**するという法則。電気加熱（赤外線加熱・抵抗炉など）の熱計算の基礎となります。

## 公式

$$J = \sigma T^4 \quad [\text{W/m}^2]$$

- $J$ : 全放射エネルギー（熱流束） $[\text{W/m}^2]$
- $\sigma$ : ステファン・ボルツマン定数（ $\approx 5.67 \times 10^{-8} \ [\text{W/(m}^2\cdot\text{K}^4)]$ ）
- $T$ : 被加熱面・熱源の絶対温度 $[\text{K}]$（ $T = t [^\circ\text{C}] + 273.15$ ）

### 実用的な放射熱移動（放射率 $\varepsilon$）
一般の物体（灰色体）間において、温度 $T_1$ の熱源から温度 $T_2$ の被加熱物への放射伝熱量 $P$ は以下のように計算されます。

$$P = \varepsilon \sigma A (T_1^4 - T_2^4) \quad [\text{W}]$$

- $\varepsilon$ : 実効放射率（形態係数を含む総合放射率）
- $A$ : 伝熱面積 $[\text{m}^2]$

> [!TIP]
> 熱伝導や対流熱伝達が温度差（ $\Delta T$ ）に比例するのに対し、放射伝熱は絶対温度の **4乗の差（ $T_1^4 - T_2^4$ ）** に比例するため、高温領域になるほど熱移動への寄与率が急激に増大します。
