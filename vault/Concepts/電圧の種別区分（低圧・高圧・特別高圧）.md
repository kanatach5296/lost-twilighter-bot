# 電圧の種別区分（低圧・高圧・特別高圧）

電気設備に関する技術基準（第2条）において定められている電圧の種別および範囲。感電事故や絶縁設計の安全基準の根幹をなします。

---

## 1. 電圧区分の定義（電技解釈）

| 電圧の種別 | 直流（DC） | 交流（AC） |
| :--- | :--- | :--- |
| **低圧** | **$750 \ \text{V}$ 以下** | **$600 \ \text{V}$ 以下** |
| **高圧** | **$750 \ \text{V}$ を超え $7000 \ \text{V}$ 以下** | **$600 \ \text{V}$ を超え $7000 \ \text{V}$ 以下** |
| **特別高圧（特高）** | **$7000 \ \text{V}$ を超えるもの** | **$7000 \ \text{V}$ を超えるもの** |

> [!NOTE] 近年の国際規格（IEC）との整合動向
> IEC規格では交流1000V以下・直流1500V以下を低圧と規定しており、日本でも太陽光発電等の直流設備や国際整合を踏まえた一部改正が行われていますが、電験三種の法規試験では伝統的な「交流600V以下／直流750V以下」が基本出題区分となっています。

---

## 2. 住宅用屋内電路の対地電圧の制限（第143条）

住宅の屋内電路における対地電圧は、原則として **$150 \ \text{V}$ 以下** と定められています。

### 例外（$300 \ \text{V}$ 以下とすることができる条件）
定格消費電力が **$2 \ \text{kW}$ 以上** の電気機械器具（エアコン、IHクッキングヒーター、電気温水器等）に電気を供給する場合：
1. **専用の分岐回路** を設けること。
2. 機械器具および配線に**簡易接触防護措置**を施すこと。
3. 電路に地絡を生じた際に自動遮断する**漏電遮断器**を施設すること。
