# 保護協調と事故報告義務（電気関係報告規則）

電力系統および需要家受電設備において、事故発生時に停電範囲を最小限に局限化する**保護協調**の原則と、波及事故時に義務付けられている**電気関係報告規則に基づく事故報告**。

---

## 1. 保護協調（Protection Coordination）の原則

受電設備を含む配電系統において、短絡や地絡が生じた際、**事故点直近上位の遮断器のみが最優先で動作**し、電源側（上位）の遮断器が不必要にトリップしないように継電器（リレー）の動作特性を整定すること。

```
   [電源] ── [遮断器A: 配電用変電所] ──┬── [遮断器B: 受電点] ── [変圧器] ── [遮断器C: 負荷側]
                                       │
                                    (事故点1: 系統)
                                                 (事故点2: 構内高圧)  (事故点3: 構内低圧)
```

### 動作時限の協調（時限協調）
- 事故点2（構内）で短絡・地絡が発生した場合：
  - **遮断器B** の動作時間（曲線2 / 曲線4）は、配電用変電所の **遮断器A** の動作時間（曲線1 / 曲線3）よりも**早く（短時間で）**動作するように整定される（動作曲線が左下側）。
- 事故点判別には、構内と構外の地絡方向を判別できる**地絡方向継電器（DGR）**が必須となります。

---

## 2. 電気関係報告規則 第3条（事故報告義務）

自家用電気工作物の設置者は、以下のような重大事故が発生した際、工作物の設置場所を管轄する**産業保安監督部長**に事故報告を行わなければなりません。

### ① 供給支障事故の報告要件
- **一般送配電事業者**の用に供する電気工作物と電気的に接続されている**電圧 $3000 \ \text{V}$ 以上**の自家用電気工作物の破損、または誤操作等により、一般送配電事業者に**供給支障**（波及事故）を発生させた場合。
- **報告対象となる事故点**: 保安上の責任分界点より需要家側の設備（上図の事故点2、受電変圧器等の破損）。

### ② 報告期限
- **速報**: 事故の発生を知った時から **48時間以内** に電話、FAX、電子メール等で概要を報告。
- **詳報**: 事故の発生を知った日から **30日以内** に詳細な報告書を提出。
