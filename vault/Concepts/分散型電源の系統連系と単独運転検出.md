# 分散型電源の系統連系と単独運転検出

太陽光発電（PV）、風力、蓄電池などの分散型電源を商用電力系統に接続（系統連系）する際の保安要件（電気設備技術基準の解釈 第220条〜第229条）。

---

## 1. 系統連系に関する重要用語の定義

| 用語 | 定義（電技解釈 第220条） |
| :--- | :--- |
| **単独運転** | 分散型電源を連系している電力系統が事故等によって系統電源と切り離された状態において、当該分散型電源が発電を継続し、**線路負荷に有効電力を供給している状態**。保安上極めて危険（公衆感電や非同期再閉路の原因）。 |
| **自立運転** | 分散型電源が、連系している電力系統から解列された状態において、**当該分散型電源設置者の構内負荷にのみ電力を供給**している状態（非常用電源としての正常運用）。 |
| **逆潮流** | 分散型電源設置者の構内から、一般送配電事業者が運用する**電力系統側へ向かう有効電力の流れ**（売電など）。 |
| **逆充電** | 分散型電源が、系統連系用変電所の遮断器開放等により停止した電力系統側へ向けて充電すること。 |

---

## 2. 単独運転検出装置の分類と検出原理

系統電源遮断時に速やかに分散型電源を解列（遮断）するため、単独運転検出装置の施設が義務付けられています。

### ① 受動的方式（パッシブ方式）
- **原理**: 単独運転移行時に生じる**電圧位相の変化**（位相躍進）、**周波数の急変**、または**第3高調波電圧歪率の変化**などの系統状態の急激な変化を受動的に捉えて検出する。
- **特徴**: 検出速度が極めて速いが、発電電力と負荷電力が完全に均衡している場合は不感帯が生じることがある。

### ② 能動的方式（アクティブ方式）
- **原理**: 分散型電源の有効電力出力または無効電力出力等に**平時から微小な変動（外乱）を与えておき**、系統電源が切り離された瞬間にその外乱に起因して生じる**周波数変動や電圧変動の増大を捉えて検出**する（周波数シフト方式、無効電力変動方式など）。
- **特徴**: 不感帯が存在しないが、常時外乱を与えるため制御が複雑となる。

> [!IMPORTANT]
> 実務および技術基準では、受動的方式と能動的方式を**併用して施設**することが標準とされています。
