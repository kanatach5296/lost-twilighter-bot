# 力率改善用コンデンサ容量

変圧器に接続された負荷群の力率を改善し、変圧器の皮相電力過負荷を防止するために必要な進相コンデンサ（電力用コンデンサ）容量 $Q_c$ の算定手法。

## 算定手順（3つのステップ）

### 1. 接続負荷の総合有効電力と無効電力の集計
各負荷の有効電力 $P_i$ と無効電力 $Q_i = P_i \tan\theta_i$ をそれぞれ合算：
$$P_{\text{total}} = \sum P_i \quad [\text{kW}]$$
$$Q_{\text{total}} = \sum Q_i \quad [\text{kvar}]$$

### 2. 変圧器定格容量に基づく許容限界無効電力 $Q_{\text{limit}}$ の算出
変圧器の定格皮相容量を $S_{\text{変圧器}} \ [\text{kVA}]$ としたとき、三平方の定理から変圧器が許容できる遅れ無効電力の上限値 $Q_{\text{limit}}$ を求めます。
$$S_{\text{変圧器}}^2 = P_{\text{total}}^2 + Q_{\text{limit}}^2 \implies Q_{\text{limit}} = \sqrt{S_{\text{変圧器}}^2 - P_{\text{total}}^2} \quad [\text{kvar}]$$

### 3. 必要な最小進相コンデンサ容量 $Q_c$
負荷の総無効電力 $Q_{\text{total}}$ を許容限界 $Q_{\text{limit}}$ まで引き下げる差分を求めます。
$$Q_c = Q_{\text{total}} - Q_{\text{limit}} \quad [\text{kvar}]$$

> [!TIP]
> 負荷力率を $\cos\theta_1$ から $\cos\theta_2$ へ改善する標準的な公式 $Q_c = P (\tan\theta_1 - \tan\theta_2)$ と本質的に同等の考え方ですが、変圧器の定格容量 $S$ から逆算するアプローチが法規・施設管理科目で頻出です。
