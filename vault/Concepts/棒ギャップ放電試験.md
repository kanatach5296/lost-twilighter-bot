# 棒ギャップ放電試験

角形または丸形の棒状電極を対向させた棒ギャップ間に高電圧を印加し、代表的な**不平等電界**における気中火花放電特性を解明するための試験。

---

## 1. 棒ギャップの電界特性と球ギャップとの相違

| 項目 | 球ギャップ（準平等電界） | **棒ギャップ（不平等電界）** |
| :--- | :--- | :--- |
| **電界分布** | 電極間全体に比較的均一（ギャップ長が球径以下の場合） | 棒電極先端に著しい**電界集中**が発生 |
| **放電プロセス** | 電圧上昇に伴い直ちに火花放電に至る | 火花放電前に**コロナ放電（部分放電）**が先行して発生 |
| **放電電圧の安定性** | 極めて安定（電圧測定標準として使用可能） | 極性（正極性／負極性）や湿度、電極形状によるバラつきが大きい |
| **破壊電圧の比較** | 同一ギャップ長では放電電圧が**高い** | 電界集中により同一ギャップ長での放電電圧は**大幅に低い** |

---

## 2. 実験プロセスとデータ解析

1. **電極間隔の調整**:
   棒電極の間隔 $d \ [\text{mm}]$ を設定する。
2. **放電電圧の測定**:
   電圧を徐々に印加し、全路破壊（火花放電）した電圧指示値を3回計測して平均値 $V_2 \ [\text{kV}]$ を算出。
3. **真の放電電圧 $V$ の換算**:
   [[球ギャップ放電と気象補正係数]] であらかじめ作成した**目盛定め曲線**のグラフから、平均指示値 $V_2$ に対応する高圧側の真の放電電圧 $V \ [\text{kV}]$ を読み取る。
4. **破壊電位の傾きの算出**:
   $$E = \frac{V}{d / 10} = \frac{10 V}{d} \quad [\text{kV/cm}]$$
5. **放電特性曲線の描画**:
   横軸をギャップ長 $d \ [\text{mm}]$、縦軸を放電電圧 $V \ [\text{kV}]$ および破壊電位の傾き $E \ [\text{kV/cm}]$ としてグラフ化し、ギャップ長増大に伴う電界緩和効果を評価する。
