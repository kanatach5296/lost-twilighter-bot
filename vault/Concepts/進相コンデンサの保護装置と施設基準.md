# 進相コンデンサの保護装置と施設基準

高圧または特別高圧の電力用コンデンサ（進相コンデンサ）に内部故障や過電流、過電圧が生じた際、火災や波及事故を防止するために電気設備技術基準の解釈（第42条）で義務付けられている保安規定。

---

## 1. コンデンサのバンク容量と自動遮断装置の施設要件

コンデンサのバンク容量（群容量）に応じて、自動的に電路から遮断する装置を施設しなければなりません。

| バンク容量 | 自動遮断すべき異常状態 |
| :--- | :--- |
| **$500 \ \text{kvar}$ を超え $15,000 \ \text{kvar}$ 未満** | **内部故障** または **過電流** が生じた場合 |
| **$15,000 \ \text{kvar}$ 以上** | **内部故障**、**過電流**、または **過電圧** が生じた場合 |

> [!WARNING] 試験頻出の引っかけポイント
> - $500 \ \text{kvar}$ 未満には法令上の自動遮断装置の施設義務はありません（過電流保護等は施されるが上記基準の対象外）。
> - **$15,000 \ \text{kvar}$ 以上** になると「**過電圧**」の保護が追加されます。

---

## 2. 残留電荷の放電装置（放電コイル・放電抵抗）

コンデンサを開放（停止）した際、残留電荷による感電や再投入時の過電圧を防止するため、放電装置を常時接続するか、開放と同時に自動接続する装置を設ける必要があります。
- **高圧コンデンサ**: 開放後 **5秒以内** に残留電圧を **$50 \ \text{V}$ 以下** に低下させる性能。
- **低圧コンデンサ**: 開放後 **3分以内** に残留電圧を **$75 \ \text{V}$ 以下** に低下させる性能。
