# 計器用変成器（VT・CT）の取扱いと留意点

高電圧・大電流の電路において、計器測定や保護継電器動作用に安全な低電圧（二次側 $110 \ \text{V}$）や小電流（二次側 $5 \ \text{A}$ または $1 \ \text{A}$）に変成する計器用変圧器（VT / PT）および変流器（CT）の運用上の厳格な安全規則。

---

## 1. 変流器（CT）の最大原則：二次側の開路厳禁！

通電中の変流器（CT）の**二次側回路を開路（オープン）してはならない**。

### ① 開路してはならない理由（事故のメカニズム）
1. **起磁力のアンバランス**:
   - 正常時、一次電流による起磁力 $I_1 N_1$ は、二次電流による逆向きの起磁力 $I_2 N_2$ によって大部分が打ち消され、鉄心内にはわずかな励磁磁束しか通りません。
2. **鉄心磁束の急増と磁気飽和**:
   - 二次側を開路すると $I_2 = 0$ となり、打ち消す起磁力が消滅するため、大電流である一次電流の全起磁力が励磁起磁力となって鉄心に集中し、鉄心が著しく磁気飽和します。
3. **異常高電圧の誘起とコイル焼損**:
   - 急峻な磁束変化により、二次巻線（巻数 $N_2$ が大きい）の両端に**数千ボルト以上のパルス状の異常高電圧が誘起**されます。
   - これにより、二次巻線の**絶縁破壊**、**コイル焼損**、および作業者の**感電死傷事故**を引き起こします。

### ② 電流計を交換・点検する際の手順
通電中に計器を交換する場合、**「必ずあらかじめCTの二次端子を短絡片（テスト端子）で短絡した後に電流計を取り外し、交換完了後に短絡を外す」** 手順を厳守します。

---

## 2. VT（計器用変圧器）とCT（変流器）の対比表

| 項目 | 計器用変圧器（VT / PT） | **変流器（CT）** |
| :--- | :--- | :--- |
| **定格二次値** | **$110 \ \text{V}$** | **$5 \ \text{A}$**（または $1 \ \text{A}$） |
| **厳禁事項** | **二次側の短絡厳禁！**<br>（過大電流により巻線が焼損する） | **二次側の開路厳禁！**<br>（異常高電圧により絶縁破壊・感電する） |
| **保護器具** | 二次側に**ヒューズ**を設置する | 二次側にヒューズや開閉器を**設けてはならない** |
| **変圧比・変流比** | 巻数比により一定 | 巻数比により一定（※二次側の負荷抵抗値を変えても変流比は変化しない） |
| **二次側接地** | 高圧用：D種接地、特高用：B種接地 | 高圧用：D種接地、特高用：B種接地 |
