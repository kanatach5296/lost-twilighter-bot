# 直流電動機の回転速度式

直流電動機において、電機子端子電圧 $V$、逆起電力 $E$、磁束 $\Phi$ および電機子電流 $I_a$ と回転速度 $N$ の関係を表す基本式。

## 回転速度 $N$ の基本式

$$N = \frac{V - I_a R_a}{k \Phi} \quad [\text{min}^{-1}]$$

- $V$ : 電機子端子電圧 $[\text{V}]$
- $I_a$ : 電機子電流 $[\text{A}]$
- $R_a$ : 電機子巻線抵抗 $[\Omega]$
- $\Phi$ : 磁極の磁束 $[\text{Wb}]$
- $k$ : 機械構造によって定まる定数

## 界磁制御の特性

界磁抵抗を増加させて界磁電流を減らし、磁極の磁束 $\Phi$ を減少させると、式の分母が小さくなるため、回転速度 $N$ は**上昇（増加）**します。

> [!WARNING] 注意
> 無負荷運転時に界磁回路が断線等で $\Phi \to 0$ に近くなると、回転速度が危険なレベルまで暴走（危険速度に達する）します。
