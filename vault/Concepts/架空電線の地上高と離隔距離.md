# 架空電線の地上高と離隔距離

電気設備技術基準の解釈（第68条、第87条〜第89条）において、公衆の安全確保や交通障害防止のために定められている架空電線路の**地上高**、建造物・道路等との**離隔距離**、および同一支持物における**併架・共架の離隔基準**。

---

## 1. 架空電線の地上高基準一覧表

| 施設場所 | 低圧架空電線 | 高圧架空電線 | **特別高圧（$35 \ \text{kV}$ 以下）** |
| :--- | :---: | :---: | :---: |
| **道路を横断する場合** | **$6.0 \ \text{m}$ 以上**<br>（交通に支障なし: $5.0\,\text{m}$） | **$6.0 \ \text{m}$ 以上** | **$6.0 \ \text{m}$ 以上** |
| **鉄道・軌道を横断する場合** | **$5.5 \ \text{m}$ 以上** | **$5.5 \ \text{m}$ 以上** | **$5.5 \ \text{m}$ 以上** |
| **横断歩道橋の上を横断する場合** | **$3.0 \ \text{m}$ 以上**<br>（絶縁・ケーブル: $3.0\,\text{m}$） | **$3.5 \ \text{m}$ 以上**<br>（ケーブル: $3.0\,\text{m}$） | **$4.0 \ \text{m}$ 以上** |
| **その他の場所** | **$5.0 \ \text{m}$ 以上**<br>（山地等: $3.5\,\text{m}$） | **$5.0 \ \text{m}$ 以上**<br>（山地等: $5.0\,\text{m}$） | **$5.0 \ \text{m}$ 以上**<br>（山地等: $5.0\,\text{m}$） |

---

## 2. $35 \ \text{kV}$ を超える特別高圧架空電線の地上高（加算式）

使用電圧が $35 \ \text{kV}$ を超える特別高圧架空電線の地上高は、$35\,\text{kV}$ を増すごとに基準値に加算率を乗じた計算値以上とします。

### ① 計算公式
基準地上高を $H_0 \ [\text{m}]$（その他の場所では $5.0 \ \text{m}$、道路横断等では $6.0 \ \text{m}$）とすると：

$$H = H_0 + 0.12 \times \frac{V - 35}{10} \quad [\text{m}]$$

- $V$ : 使用電圧 $[\text{kV}]$
- $\frac{V - 35}{10}$ の端数処理：**小数点以下を切り上げて整数**とする（10kV刻み）。

> [!TIP] 計算演習例（$154 \ \text{kV}$ 送電線・その他場所）
> - $\frac{154 - 35}{10} = \frac{119}{10} = 11.9 \to$ 切り上げて **$12$**
> - $H = 5.0 + 0.12 \times 12 = 5.0 + 1.44 = \mathbf{6.44 \ \text{m}}$ 以上

---

## 3. 同一支持物に併架する場合の離隔距離

同一の電柱・鉄塔に高圧線と低圧線、または特別高圧線と高低圧線を併架する場合：

- **高圧電線と低圧電線の離隔距離**:
  - 原則：**$0.5 \ \text{m}$（$50\,\text{cm}$）以上**
  - 高圧側に**ケーブル**を使用する場合：**$0.3 \ \text{m}$（$30\,\text{cm}$）以上** に緩和可能。
- **配置関係**:
  - 高圧電線は低圧電線の**上方**に配置する。
