# A種・C種接地工事の施設基準

電気設備技術基準の解釈（第17条〜第29条）において、感電防止・火災防止・機器保護のために定められている4種類の接地工事のうち、高圧・特別高圧機器に施す**A種接地工事**および $300\,\text{V}$ 超の低圧機器に施す**C種接地工事**の施設基準。

---

## 1. 接地工事の4大区分・基準一覧表

| 接地工事 | 主な施設対象 | 規定接地抵抗値 | 遮断器連動による緩和 | 接地線の太さ（最小） |
| :---: | :--- | :---: | :---: | :---: |
| **A種** | 高圧・特高用機械器具の金属製外箱、避雷器、計器用変成器外箱 | **$10 \ \Omega$ 以下** | 緩和なし | 直径 **$2.6 \ \text{mm}$** 以上の軟銅線（引張強さ 1.04kN） |
| **B種** | 変圧器の低圧側中性点（混触防止） | **$R_B = \dfrac{150 \sim 600}{I_1}$** | 遮断時間により $300/I_1$ または $600/I_1$ | 直径 **$4.0 \ \text{mm}$** 以上の軟銅線（高低圧混触時は $2.6\,\text{mm}$） |
| **C種** | **$300 \ \text{V}$ を超える**低圧用機械器具の外箱・金属管 | **$10 \ \Omega$ 以下** | **0.5秒以内遮断**で **$500 \ \Omega$ 以下** | 直径 **$1.6 \ \text{mm}$** 以上の軟銅線 |
| **D種** | **$300 \ \text{V}$ 以下の**低圧用機械器具の外箱・金属管 | **$100 \ \Omega$ 以下** | **0.5秒以内遮断**で **$500 \ \Omega$ 以下** | 直径 **$1.6 \ \text{mm}$** 以上の軟銅線 |

---

## 2. 接地工事の省略条件（特例規定）

以下のいずれかに該当する場合、機械器具の金属製外箱の C種・D種接地工事を省略することができます。

1. **対地電圧 150V 以下の機械器具を乾燥した場所に施設する場合**。
2. **低圧用の機械器具を乾燥した木製の床その他これに類する絶縁性の物の上で取り扱うように施設する場合**。
3. **電気用品安全法の適用を受ける二重絶縁構造の機械器具を施設する場合**。
4. **低圧用の機械器具に電気を供給する電路に、感度電流 $15\,\text{mA}$ 以下、動作時間 $0.1$ 秒以下の漏電遮断器を施設する場合**（水気のある場所以外）。

> [!WARNING] 試験頻出ポイント
> - **高圧機械器具の金属製外箱** は、原則として **A種接地工事** が義務付けられます（D種接地とする選択肢は誤り）。
> - C種接地とD種接地の境界は「使用電圧 **$300 \ \text{V}$**」です。
