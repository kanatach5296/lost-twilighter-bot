# B種接地工事

変圧器の高圧側（または特別高圧側）電路と低圧側電路の混触による危険を防止するため、変圧器の低圧側の中性点（中性点に接地し難い場合は低圧側端子の1端子）に施す接地工事。

## 接地抵抗値 $R_B$ の規定（電気設備技術基準の解釈 第17条）

高圧電路の1線地絡電流を $I_1 \ [\text{A}]$ としたときの最大接地抵抗値：

| 遮断装置の条件 | 許容最大接地抵抗値 $R_B$ | 根拠（許容混触電圧） |
| :--- | :--- | :--- |
| **原則（自動遮断装置なし）** | **$R_B = \dfrac{150}{I_1} \quad [\Omega]$** | 対地電圧を $150\,\text{V}$ 以下に抑える |
| **1秒超2秒以内に自動遮断する装置あり** | **$R_B = \dfrac{300}{I_1} \quad [\Omega]$** | 対地電圧を $300\,\text{V}$ 以下に抑える |
| **1秒以内に自動遮断する装置あり** | **$R_B = \dfrac{600}{I_1} \quad [\Omega]$** | 対地電圧を $600\,\text{V}$ 以下に抑える |

> [!NOTE] 計算上の端数処理
> - 計算値に小数点以下の端数が出た場合、電気設備技術基準の規定に基づき、通常は小数点以下を**切り捨て**て整数値とします（安全側にするため）。
## 📌 過去問での出題実績・問われ方
- **[[電験三種 令和6年下期 法規 全問攻略MOC|R06下期 問4]]**: 1秒以内自動遮断装置あり（$R_B = 600/I_1$）における架空線路延長 $L=20\,\text{km}$ からの地絡電流計算と接地抵抗上限値算定（$R_B = 300\,\Omega$）。
- **[[電験三種 令和6年下期 法規 全問攻略MOC|R06下期 問12]]**: 1.3秒遮断装置（1秒超2秒以内 $\to R_B = 300/I_1 = 60\,\Omega$）および対地静電容量 $C=0.1\,\mu\text{F}$ を介して常時大地に流れる漏れ電流計算（$I_B \approx 11\,\text{mA}$）。
- **[[電験三種 令和5年下期 法規 全問攻略MOC|R05下期 問3]]**: 電路の絶縁原則と高低圧混触防止のための接地。
