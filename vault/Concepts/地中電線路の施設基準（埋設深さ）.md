# 地中電線路の施設基準（埋設深さ）

電線路を地下に布設する地中電線路において、外傷防止・保安確保のために電気設備技術基準の解釈（第120条等）で定められている施設方法および埋設深さの基準。

---

## 1. 3つの布設方式

地中電線路には原則として**ケーブル**を使用し、以下のいずれかの方式により施設します。

1. **直接埋設式（直埋式）**:
   - ケーブルを堅ろうなトラフ（石綿セメント管、コンクリートトラフ等）または防護板に収めて埋設。
2. **管路式**:
   - 地中に陶管・鋼管・合成樹脂管等を埋設し、その中にケーブルを引き入れる。一定区間ごとにマンホール（人孔）を設置。
3. **暗きょ式（とう道式）**:
   - 人が立ち入って点検できる共同溝やトンネル（とう道）内にケーブルをラック等で支持して布設。

---

## 2. 埋設深さ（土被り）の基準値

| 施設場所 | 規定埋設深さ（土被り） | 備考 |
| :--- | :--- | :--- |
| **車両その他の重量物の圧力を受ける場所**（車道・駐車場等） | **$1.0 \ \text{m}$ 以上**<br>（※旧基準は $1.2 \ \text{m}$ 以上） | 平成10年代の基準改定により $1.2\text{m} \to 1.0\text{m}$ に変更 |
| **その他の場所**（歩道・敷地内等） | **$0.6 \ \text{m}$ 以上** | |

> [!IMPORTANT] 地中電線路の明示義務
> 地中電線路である旨、および**物件の名称**、**管理者名**、**電圧**（高圧または特別高圧）を地上に一定間隔で標示シートや標柱等によって明示しなければなりません。
