# D種接地工事

300V以下の低圧用機械器具の金属製外箱、鉄台、金属管等に施す接地工事。感電防止および火災防止を目的とします。

## 接地抵抗値 $R_D$ の基準

| 施設条件 | 規定接地抵抗値 |
| :--- | :--- |
| **原則** | **$100 \ \Omega$ 以下** |
| **低圧電路において地絡を生じた際に0.5秒以内に自動遮断する漏電遮断器を施設する場合** | **$500 \ \Omega$ 以下** |

> [!NOTE] 接地線の太さ
> - 接地線には、直径 $1.6\,\text{mm}$ 以上の軟銅線（移動して使用する電気機械器具はキャブタイヤケーブル等）を使用します。
