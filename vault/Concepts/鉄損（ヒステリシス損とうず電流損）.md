# 鉄損（ヒステリシス損とうず電流損）

変圧器や回転機などの鉄心（磁気回路）内に交番磁界が加わることによって生じる内部エネルギー損失。**ヒステリシス損**と**うず電流損**の2つの合計で構成されます。

$$\text{鉄損 } W_i = \text{ヒステリシス損 } W_h + \text{うず電流損 } W_e$$

---

## 1. 鉄心材料に求められる4大要求性能

高効率な変圧器・電気機器を設計するために、鉄心材料（磁性材料）には以下の電磁気的特性が求められます。

1. **飽和磁束密度が大きいこと**:
   - より強い磁束を通すことができ、鉄心断面積を小さく（小型軽量化）できる。
2. **透磁率（および電気抵抗率）が大きいこと**:
   - 少ない励磁電流で十分な磁束を発生でき、抵抗率が大きいほどうず電流を抑制できる。
3. **保持力が小さいこと**:
   - ヒステリシスループの幅が狭くなり、ヒステリシス損を低減できる。
4. **残留磁気が小さいこと**:
   - 磁化反転時の残留エネルギー損失を抑えられる。

---

## 2. 損失の分類と低減手法

### ① ヒステリシス損 $W_h$
- **メカニズム**: 交番磁界による磁区の回転・反転の摩擦エネルギーに起因する損失（ヒステリシスループの面積に比例）。
- **低減法**: 材料の**保持力**および**残留磁気**を小さくする（シリコン添加や結晶制御）。
- **ステインメッツの実験式**: $W_h = \eta f B_m^{1.6 \sim 2.0}$

### ② うず電流損（渦電流損）$W_e$
- **メカニズム**: 時間変化する交番磁束によってファラデーの電磁誘導の法則に従い鉄心内に生じる起電力と、それにより流れる渦電流によるジュール熱。
- **低減法**:
  1. 電気抵抗率を大きくする（ケイ素鋼など）。
  2. 薄板（$0.30 \sim 0.50 \ \text{mm}$ 程度）表面に絶縁被膜を施した**積層構造**（積層鉄心）にする。
- **公式**: $W_e \propto \dfrac{f^2 d^2 B_m^2}{\rho}$ （$d$: 板厚, $\rho$: 抵抗率）

> [!NOTE]
> 鉄損は負荷の大きさ（電流）によらず、電源電圧（磁束密度 $B$）と周波数 $f$ で決まるため「無負荷損（固定損）」と呼ばれます。鉄損が少ないほど変圧器の**効率**が向上します。
