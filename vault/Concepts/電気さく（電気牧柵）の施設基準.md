# 電気さく（電気牧柵）の施設基準

田畑、牧場その他これに類する場所において、野獣の侵入または家畜の脱出を防止するために施設する**電気さく（電気牧柵）**に関する安全・感電防止規定（電気設備技術基準 第74条、解釈 第192条）。

---

## 1. 設置原則と禁止の例外

電気さく（屋外において裸電線を固定して施設したさくであって、その裸電線に充電して使用するもの）は、原則として施設してはならないが、**以下の条件を満たす場合に限り例外的に施設が認められます**。

1. **目的の限定**:
   - 田畑、牧場その他これに類する場所において、**野獣の侵入又は家畜の脱出を防止**するためであること。
2. **危険の表示**:
   - 人の見やすい位置に適当な間隔で**「危険である旨の表示」**（電気さくである旨）を掲示すること。
3. **電波障害の防止**:
   - 衝撃電流発生時の電波又は高周波電流が無線設備の機能に継続的かつ重大な障害を与えないこと。

---

## 2. 電源装置と漏電遮断器の安全要件

電気さくへ電気を供給する電源および保安装置には、以下の厳格な基準が定められています。

| 項目 | 規定内容 |
| :--- | :--- |
| **適合電源装置** | ・電気用品安全法（PSE）の適用を受ける電気さく用電源装置<br>・感電により人体に危険を及ぼすおそれのない直流電源（蓄電池、太陽電池等） |
| **商用交流電源を使用する場合** | 直流電源装置を介して電気の供給を受ける場合で、直流電源装置の使用電圧が **$30 \ \text{V}$ 以上** の電路から供給を受けるときは、電路に適合する**漏電遮断器**を施設すること。 |
| **漏電遮断器の性能基準** | ① 電流動作型のものであること。<br>② **定格感度電流が $15 \ \text{mA}$ 以下** であること。<br>③ **動作時間が $0.1$ 秒以下** であること。 |
| **専用開閉器** | 電気さくに電気を供給する電路には、容易に開閉できる箇所に**専用の開閉器**を施設すること。 |

> [!WARNING] 試験の出題パターン
> 「定格感度電流 **$15 \ \text{mA}$ 以下**」「動作時間 **$0.1$ 秒以下**」「使用電圧 **$30 \ \text{V}$ 以上**」の数値が穴埋め・正誤判定で定番です（西伊豆での感電死亡事故を受けた基準強化の背景があります）。
