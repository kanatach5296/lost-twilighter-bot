# インパルス電圧発生装置

電力系統に侵入する雷サージ（急峻な雷過電圧）や開閉サージに対する電気機器の耐電圧性能（絶縁協調）を検証するため、人工的に極短時間の衝撃高電圧波形を発生させる試験装置。

---

## 1. マルクス回路（Marx回路）の動作原理

インパルス電圧発生装置は、多段のコンデンサと放電ギャップ、波形調整抵抗で構成されます。

1. **並列充電**:
   - 直流高電圧電源から高抵抗を介して、各段の主コンデンサを**並列に充電**する。
2. **直列放電（トリガ動作）**:
   - 初段のギャップが点弧（放電）すると、段間の電位差が急変して全段のギャップが瞬時に連鎖放電し、全コンデンサが**直列に接続**されて極めて高い合成電圧を出力する。
3. **標準雷インパルス波形**:
   - 波頭長 $1.2 \ \mu\text{s}$、波尾長 $50 \ \mu\text{s}$ の標準波形（$1.2 / 50 \ \mu\text{s}$）を生成。

---

## 2. 50%放電電圧と全充電電圧 $V_c$ の測定手順

インパルス放電は確率現象（統計的遅延や形成遅延）であるため、放電率によって耐電圧値を定義します。

1. **ギャップ調整**:
   - 電圧測定用球ギャップの間隔を規定値にセットし、標準放電電圧を確認する。
2. **10回印加試験**:
   - 正極性（または負極性）で充電し、始動ボタンによりインパルス電圧を発生させる。
   - 同一の充電電圧で **10回** 連続印加し、球ギャップが火花放電した回数をカウントして**放電率 $[\%]$**（放電回数／10）を調べる。
3. **50%放電電圧（全充電電圧 $V_c$）の同定**:
   - 充電電圧を微調整し、**放電率がちょうど 50%**（10回中5回放電）となる充電電圧を見出す。このときの充電電圧を**全充電電圧 $V_c \ [\text{kV}]$** として記録する。

---

## 3. 装置の利用率（波高値効率）

インパルス発生装置の定格最大出力電圧を $V_{\text{output\_max}}$（手順書では $300 \ \text{kV}$）としたとき、全充電電圧 $V_c$ が定格出力の何％に相当するかを**利用率**として算出します。

$$\text{利用率 } \eta = \frac{V_c}{V_{\text{output\_max}}} \times 100 \quad [\%]$$

> [!TIP]
> 横軸に全充電電圧 $V_c \ [\text{kV}]$、縦軸に出力電圧 $V \ [\text{kV}]$ をプロットすることで、発生装置の入出力直線性および回路効率を把握できます。
