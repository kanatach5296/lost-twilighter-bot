# 負荷の電圧特性

受電端電圧 $V_r$ の変動に対する負荷の消費電力（有効電力 $P_r$、無効電力 $Q_r$）の応答特性。電力系統の[[電圧安定度と電圧崩壊|電圧安定度]]に極めて大きな影響を与えます。

---

## 1. 負荷特性の基本モデル式

受電端の基準電圧を $V_0$、基準電圧時の電力をそれぞれ $P_0, Q_0$ とすると、一般に以下の指数モデルで表されます。

$$P_r = P_0 \left(\frac{V_r}{V_0}\right)^\alpha, \quad Q_r = Q_0 \left(\frac{V_r}{V_0}\right)^\beta$$

---

## 2. 負荷の3大分類

| 特性区分 | 指数 $\alpha, \beta$ | 特性と数式 | 代表例 | 電圧安定度への影響 |
| :--- | :--- | :--- | :--- | :--- |
| **定電力特性** | **$\alpha = 0, \beta = 0$** | 電圧が変化しても消費電力が一定（$P = P_0$） | **インバータエアコン**、スイッチング電源、制御された誘導電動機 | **最も厳しい（悪影響大）**<br>電圧低下時に電力を維持しようと電流 $I$ が増大するため、送電線の電圧降下を加速させる。 |
| **定電流特性** | **$\alpha = 1, \beta = 1$** | 電流が一定（電力は電圧に比例 $P \propto V$） | **蛍光灯**、整流器負荷、アーク炉 | 中程度 |
| **定インピーダンス特性** | **$\alpha = 2, \beta = 2$** | インピーダンスが一定（電力は電圧の2乗に比例 $P \propto V^2$） | **白熱灯**、**電熱器（ヒーター）** | **安定（自律回復性あり）**<br>電圧低下に伴い消費電力が急減するため、系統の電圧降下を緩和する。 |

```
   電圧 V ↑
          │                定電力特性（P一定：インバータエアコン等）
          │                  │
          │                  │   定インピーダンス特性（P∝V²：電熱器等）
          │                  │  ／
          │                  │／   定電流特性（P∝V：蛍光灯等）
          ├──────────────────●────／──────────────
          │                 定格点(P0, V0)
          │                  │
          └──────────────────┴────────────────────→ 有効電力 P
```

---

## 3. P-V曲線との交点と電圧安定性

1. **定電力負荷の挙動**:
   - [[P-V曲線（ノーズカーブ）]] 上で定電力負荷は垂直直線（$P = P_L$）として表されます。
   - 負荷が増加すると垂直線が**右側へ平行移動**し、ノーズ点（限界点）を超えると交点（解）が存在しなくなって電圧崩壊に至ります。
2. **負荷全体に占める定電力負荷の比率**:
   - 負荷全体に占める**定電力負荷の割合が「大きい」場合**、系統の電圧維持は非常に厳しくなります。現代のインバータ家電や電子機器の普及が電圧安定度対策をより重要にしています。
