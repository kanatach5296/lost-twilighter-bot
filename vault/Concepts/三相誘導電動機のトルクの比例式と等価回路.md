# 三相誘導電動機のトルクの比例式と等価回路

三相誘導電動機の一次換算等価回路から導かれる電力推移（パワーフロー）の基本関係式、発生トルク $T$ の算定公式、および最大トルク特性。

---

## 1. 誘導機のパワーフロー（$1 : s : 1-s$ の黄金比）

回転子（二次側）に電磁誘導によって伝送される電力（二次入力 $P_2$）、回転子の抵抗損（二次銅損 $P_{c2}$）、および回転エネルギーに変換される電力（内部機械出力 $P_m$）の間には、すべり $s$ を媒介として以下の厳密な比例関係が成立します。

$$P_2 : P_{c2} : P_m = 1 : s : (1 - s)$$

- **二次銅損**: $P_{c2} = s P_2 = 3 I_2'^2 r_2' \quad [\text{W}]$
- **内部機械出力**: $P_m = (1 - s) P_2 = \frac{1 - s}{s} P_{c2} \quad [\text{W}]$
- **二次効率**: $\eta_2 = \frac{P_m}{P_2} = 1 - s$

---

## 2. 発生トルク $T$ の計算公式

同期角速度を $\omega_s = \frac{2\pi N_s}{60} \ [\text{rad/s}]$、回転子の実際の角速度を $\omega = \omega_s (1 - s) \ [\text{rad/s}]$ とすると：

$$T = \frac{P_m}{\omega} = \frac{(1 - s) P_2}{\omega_s (1 - s)} = \mathbf{\frac{P_2}{\omega_s}} = \frac{60 P_2}{2\pi N_s} \quad [\text{N}\cdot\text{m}]$$

> [!IMPORTANT]
> 機械出力 $P_m$ を実回転速度 $\omega$ で割っても、二次入力 $P_2$ を**同期速度 $\omega_s$** で割っても同一のトルク $T$ が得られます。二次入力 $P_2$ は「同期ワット」とも呼ばれます。

---

## 3. トルクと電圧・二次抵抗の比例特性

1. **印加電圧との関係**:
   - 発生トルク $T$ は、電源端子電圧 $V$ の **2乗に比例** します（$T \propto V^2$）。
2. **比例推移との関係**:
   - 最大トルク $T_{\text{max}}$ の大きさは二次抵抗 $r_2'$ に無関係で一定。
   - 二次抵抗 $r_2'$ を増加させると、最大トルクを生じるすべり $s_{\text{max}}$ が比例して増大します（$\frac{r_2'}{s} = \text{一定}$）。
