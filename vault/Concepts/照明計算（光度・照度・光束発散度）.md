# 照明計算（光度・照度・光束発散度）

電気応用（照明工学）における光の基本諸量（光束、光度、照度、輝度）と点光源からの照度計算、および部屋全体の平均照度を求める**光束法**の計算公式。

---

## 1. 光の基本単位と定義

- **光束 $F$** $[\text{lm}]$（ルーメン）：光源から放射される可視光の総エネルギー流量。
- **光度 $I$** $[\text{cd}]$（カンデラ）：特定方向への単位立体角あたりの光束（$I = \frac{dF}{d\omega}$）。
- **照度 $E$** $[\text{lx}]$（ルクス）：受照面の単位面積あたりに入射する光束（$E = \frac{dF}{dA}$）。
- **輝度 $L$** $[\text{cd/m}^2]$：光源または反射面を見たときの見かけの明るさ（正射影面積あたり光度）。

---

## 2. 点光源による照度計算（逆2乗の法則と余弦則）

高さ $h \ [\text{m}]$ の位置にある光度 $I(\theta) \ [\text{cd}]$ の点光源から、距離 $r \ [\text{m}]$（鉛直方向からの角度 $\theta$）離れた点 P の照度：

```
      光源 ● (光度 I)
          │＼
          │  ＼
        h │    ＼ r
          │      ＼
          │ θ      ＼
          ┴─────────● P 点
               d
```

1. **法線照度 $E_n$**:
   光線に垂直な面における照度：
   $$E_n = \frac{I(\theta)}{r^2} \quad [\text{lx}]$$
2. **水平面照度 $E_h$**:
   床面・机上面（水平面）における照度：
   $$E_h = E_n \cos\theta = \frac{I(\theta)}{r^2} \cos\theta = \frac{I(\theta)}{h^2} \cos^3\theta \quad [\text{lx}]$$
3. **垂直面照度 $E_v$**:
   壁面などの垂直面における照度：
   $$E_v = E_n \sin\theta = \frac{I(\theta)}{r^2} \sin\theta = \frac{I(\theta)}{h^2} \cos^2\theta \sin\theta \quad [\text{lx}]$$

---

## 3. 全体平均照度を求める光束法

間口 $X \ [\text{m}]$、奥行き $Y \ [\text{m}]$（床面積 $A = X Y \ [\text{m}^2]$）、作業面から光源までの高さ $H \ [\text{m}]$ の室内において：

### ① 室指数 $K$
室内の形状比率を表す指標（天井・壁からの反射光の寄与率を決定）：
$$K = \frac{X Y}{H (X + Y)}$$

### ② 光束法の基本公式
室内の平均照度を $E \ [\text{lx}]$、器具1台あたりのランプ光束を $F \ [\text{lm}]$、器具台数を $N$、照明率を $U$、保守率を $M$（または減光補償率 $D = 1/M$）とすると：

$$F N U M = E A \implies \mathbf{F = \frac{E A D}{N U}} = \frac{E A}{N U M} \quad [\text{lm}]$$

- $U$ : 照明率（光源から出た全光束のうち、作業面に到達する光束の割合）
- $M$ : 保守率（光源の経年減光や汚れによる照度低下を見込んだ係数 $M < 1$）
- $D$ : 減光補償率（$D = \frac{1}{M} > 1$）
