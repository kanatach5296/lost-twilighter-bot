# P-V曲線（ノーズカーブ）

電力系統において、受電端の有効電力 $P$（横軸）と受電端電圧 $V$（縦軸）の関係を表した特性曲線。曲線の先端が鼻（ノーズ）のような形状をしていることから**ノーズカーブ**とも呼ばれます。

---

## 1. 曲線上の特徴点と運転領域

ある一定の有効電力需要 $P = P_L$ に対し、数学的には2つの解が存在します。

```
   受電端電圧 V ↑
               │
               │   高め解（安定運転点 A）
               ├─────────●──────────────────╮
               │         │                  │
               │         │ 安定余裕          │
               │         │<───────────────> │
               │         │                  ● ノーズ点（限界点 B）
               │         │                  │
               │   低め解（不安定点 C）     │
               ├─────────●──────────────────╯
               │         │
               └─────────┴─────────────────────→ 有効電力 P
                        P_L
```

1. **安定運転点（A点・高め解）**:
   - 電圧が高く電流が小さいため送電損失が少ない。電力増加に対して電圧がわずかに低下する自然な負帰還が働き、**安定に運用できる点**。
2. **ノーズ点（B点・電圧安定限界点 / 潮流限界点）**:
   - 送電できる有効電力の最大値（極大値）。この点を超えると平衡解が消失し、[[電圧安定度と電圧崩壊|電圧崩壊]]に至る。
3. **不安定点（C点・低め解）**:
   - 同一電力を送るために極端に大きな電流が流れ、線路リアクタンス損（$I^2 X$）が激増して電圧降下が拡大する**不安定な領域**。

---

## 2. 各パラメータとP-V曲線の変動特性

| パラメータの変化 | P-V曲線の挙動（ノーズ点の移動） | 電圧安定度への影響 |
| :--- | :--- | :--- |
| **負荷力率の改善（進み側へ）** | 限界点が**右上へ移動（曲線が拡大）** | 安定度が向上する |
| **負荷力率の悪化（遅れ側へ）** | 限界点が**左下へ縮小** | 安定度が低下する |
| **調相設備（[[力率改善用コンデンサ容量|電力用コンデンサ]]）の投入** | 限界点が**右上（右方向）へ移動** | 安定度が向上する |
| **送電線リアクタンス $X$ の減少** | 限界点が**右側へ移動** | 安定度が向上する |
| **送電端電圧 $E$ の上昇** | 限界点が**上側へ移動** | 安定度が向上する |

> [!TIP] 試験頻出ポイント（問題演習より）
> - 負荷端に**電力用コンデンサ**を投入すると、P-V曲線の限界点が**「右上（右）」**方向に移動し、電圧の安定性を向上させることができます。
> - 遅れ負荷力率が大きくなるほど、P-V曲線は内側に縮小します。
