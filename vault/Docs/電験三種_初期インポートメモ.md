## １．電力科目（水力・汽力・変電・送配電）

### 📘 重要用語・公式

- **水力発電の理論水力 \(P\)** \[P = 9.8 Q H \ [\text{kW}]\] （ \(Q [\text{m}^3/\text{s}]\) は流量、\(H [\text{m}]\) は有効落差）
- **ベルヌーイの定理（水力）** 位置水頭 \(h [\text{m}]\)、圧力水頭 \(\frac{p}{\rho g} [\text{m}]\)、速度水頭 \(\frac{v^2}{2g} [\text{m}]\) の和は一定。
- **速度調定率による出力変化量 \(\Delta P\)** \[\Delta P = \frac{\Delta f}{f_n} \times \frac{P_n}{R} \times 100 \ [\text{MW}]\] （ \(\Delta f\) は周波数変化量、\(f_n\) は定格周波数、\(P_n\) は定格出力、\(R\) は速度調定率 \([%]\) ）
- **配電線の簡易電圧降下式 \(\Delta V\)**
    - **単相2線式**: \(\Delta V = 2 I (r \cos\theta + x \sin\theta) \ [\text{V}]\)
    - **三相3線式**: \(\Delta V = \sqrt{3} I (r \cos\theta + x \sin\theta) \ [\text{V}]\)
- **送電線の電圧降下近似式（三相3線式）** \[v = \frac{r P + x Q}{V_r} \ [\text{V}]\] （ \(P\) は有効電力、\(Q\) は無効電力、\(V_r\) は受電端電圧）
- **電線のたるみ（弛度） \(D\)** \[D = \frac{W S^2}{8 T} \ [\text{m}]\] （ \(W\) は電線1mあたりの荷重 \([\text{N/m}]\)、\(S\) は径間 \([\text{m}]\)、\(T\) は水平張力 \([\text{N}]\) ）

---

### 🔍 つまずきやすい計算＆仕組みの解説

#### 1. 周波数低下に伴う発電機の負荷分担計算

- **仕組み**: 系統の周波数が低下した際、ガバナ（調速機）が自動応動して発電出力を増加させます。
- **ポイント**: 周波数の低下率（ \(\frac{\Delta f}{f_n}\) ）を計算し、それぞれの発電機の速度調定率 \(R\) で割ることで「定格出力の何％分を出力アップさせるか」を算出します。

#### 2. 単相2線式と単相3線式の損失・電流比較

- **仕組み**: 同一負荷電力 \(P\) を送電する場合、単相3線式（外線間 200V）は単相2線式（100V）に比べて線路電流が半分（ \(I_3 = \frac{1}{2} I_2\) ）になります。
- **ポイント**: 中性線に電流が流れない平衡負荷時、単相3線式の線路電力損失は単相2線式の **0.8倍（80%）**、または同心等長電線条件により一定の低減効果が得られます。

## ２．機械科目（直流機・同期機・誘導機・パワエネ・電気加熱・自動制御）

### 📘 重要用語・公式

#### ① 直流機

- **回転速度の基本式 \(N\)** \[N = \frac{V - I_a R_a}{k \Phi} \ [\text{min}^{-1}]\]
    - **界磁制御**: 界磁電流（磁束 \(\Phi\)）を減少させると、分母が小さくなるため回転速度 \(N\) は**上昇（増加）**します。

#### ② 誘導機

- **スターデルタ（Y-Δ）始動法**
    - 始動時の電圧は \(\frac{1}{\sqrt{3}}\) 倍。
    - 始動電流および始動トルクは全電圧始動（Δ結線）の **\(\frac{1}{3}\) 倍**。
- **巻線形三相誘導電動機の比例推移**
    - 二次抵抗 \(R_2\) を増加させると、**最大トルクの値は変化せず**、最大トルクを発生する「すべり \(s\)」が大きくなります。また、**始動トルクは大きく**なります。

#### ③ 同期機

- **同期インピーダンス \(Z_s\) と短絡比** \[Z_s = \frac{V_n / \sqrt{3}}{I_s} \ [\Omega]\]
- **起動法（制動巻線）** 回転子の磁極面に**制動巻線**（かご形構造）を施し、誘導トルクによって起動します。起動時は高電圧誘起による絶縁破壊を防ぐため、界磁巻線を抵抗で短絡します。

#### ④ パワーエレクトロニクス・電気加熱・自動制御

- **誘導加熱の原理**
    - 導電性被加熱物を交番磁束内におくことで渦電流が生じ、ジュール熱で加熱されます。
    - **表皮効果**: 周波数が**高い**ほど電流浸透深さ \(\delta\) は**浅く**なり、表面集中度が強まります。
- **熱計算（ステファン・ボルツマンの法則）** 放射熱束 \(J = \sigma T^4 \ [\text{W/m}^2]\) （放射エネルギーは絶対温度 \(T\) の **4乗に比例** ）。

---

### 🔍 つまずきやすい計算＆仕組みの解説

#### 1. 変圧器の短絡試験と漏れリアクタンス \(x\) の算定

- **公式**: \(x = \sqrt{Z^2 - r^2}\)
- **手順**:
    1. インピーダンス \(Z = \frac{V}{I}\) を求める。
    2. 抵抗 \(r = \frac{P}{I^2}\) を求める。
    3. ピタゴラスの定理により漏れリアクタンス \(x\) を導出します。

#### 2. 単相半波ダイオード整流回路とインダクタンス \(L\) の放出期間

- **仕組み**: 交流電圧が負の領域に入っても、インダクタンス \(L\) に蓄えられたエネルギーが放出されるため、電流は直ちにゼロにならずダイオードを通って流れ続けます。

## ３．法規科目（電気設備技術基準・関係法令・施設管理）

### 📘 重要用語・公式

#### ① 接地工事の規定

- **B種接地抵抗値 \(R_B\)**
    - **原則（自動遮断なし）**: \(R_B = \frac{150}{I_1} \ [\Omega]\)
    - **1秒超2秒以内に自動遮断する装置あり**: \(R_B = \frac{300}{I_1} \ [\Omega]\)
    - **1秒以内に自動遮断する装置あり**: \(R_B = \frac{600}{I_1} \ [\Omega]\) （ \(I_1\) は高圧電路の 1線地絡電流 \([\text{A}]\) ）
- **D種接地抵抗値 \(R_D\)**
    - **原則**: \(100 \ [\Omega]\) 以下
    - **0.5秒以内に自動遮断する漏電遮断器を施設する場合**: \(500 \ [\Omega]\) 以下

#### ② 低圧電路の絶縁抵抗値（最小値）

- **対地電圧 150V 以下**: **\(0.1 \ \text{M}\Omega\) 以上**
- **対地電圧 150V 超 〜 300V 以下**: **\(0.2 \ \text{M}\Omega\) 以上**
- **使用電圧 300V 超**: **\(0.4 \ \text{M}\Omega\) 以上**

#### ③ 電気工事業法における営業所の備え付け測定器具

- 一般用電気工作物の工事を行う営業所に義務付けられているのは**「絶縁抵抗計」「接地抵抗計」「回路計（テスター）」**の3点です（※クランプ電流計は含まれません）。

---

### 🔍 つまずきやすい計算＆仕組みの解説

#### 1. 支線の強度および最小素線数の計算

1. **電線の水平合成荷重 \(F_0\)**: 電線の屈曲角（例： \(60^\circ\)）から合成力 \(F_0 = 2 T \cos 60^\circ\) を算出。
2. **てこの原理（モーメント平衡）**: 電線取付高さ \(h_1\) と支線取付高さ \(h_2\) から、支線位置の水平力 \(F_H = F_0 \times \frac{h_1}{h_2}\) を算出。
3. **斜め方向張力 \(F_{\text{max}}\)**: 直角三角形の寸法比（ \(\frac{\text{斜辺}}{\text{底辺}}\) ）を掛けて斜め張力を求める。
4. **安全率（1.5以上）と減少係数の適用**: \[\text{必要素線数} = \frac{F_{\text{max}} \times 1.5}{\text{素線1本の強さ} \times \text{減少係数}}\] 算出された値は安全のため切り上げて整数とします。

#### 2. 太陽光発電電力と負荷持続曲線の重なり（余剰電力・自給率）

- **余剰送電量**: 直線的に変化する太陽光発電電力（例: 1時間あたり100kW変化）と、段階的に変化する需要電力の差（飛び出した部分の面積＝三角形や台形）を計算して合算します。
- **自給率**: \[\text{自給率 [%]} = \frac{\text{全発電量} - \text{余剰送電量}}{\text{一日の全消費電力量}} \times 100\]

#### 3. 変圧器の過負荷防止に必要な最小コンデンサ容量 \(Q_c\)

1. 接続されている負荷の全有効電力 \(P_{\text{total}}\) と全無効電力 \(Q_{\text{total}}\) を集計する。
2. 変圧器容量 \(S_{\text{変圧器}}\) に対し、許容される限界の無効電力 \(Q_{\text{limit}} = \sqrt{S_{\text{変圧器}}^2 - P_{\text{total}}^2}\) を計算する。
3. 必要コンデンサ容量 \(Q_c = Q_{\text{total}} - Q_{\text{limit}}\) を求める。
