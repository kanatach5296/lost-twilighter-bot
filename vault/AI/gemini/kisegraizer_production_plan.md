# 3作目『キセグライザー (KISEGRAIZER)』企画・構成・トラック・歌詞設計まとめ

『フューチャーページ』▶︎『ライフリバース』に続く3作目として、これまでの議論で確定したコンセプト、タイトル、全体構成、音響スペック、サビ頭の歌詞・譜割り案、および制作プロセスを網羅したマスター設計書です。

## 3. 全体構成タイムライン（全10セクション）

「1番は王道エモに偽装 ──> 1サビ終わりから落ちサビインまでは徹底的にかっこよく裏切る ──> 落ちサビで泣かせて ──> ラスサビでさらに強く泣かせて ──> アウトロは銀河口上で完全燃焼」という黄金構成です。

| 順 | セクション | 小節 | モード・感情 | トラック・ビート・ボーカルの仕掛け |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **サビ予告ワンフレーズ** | 2 | **掴み（ドライ）** | BGM完全無音。至近距離のアカペラでサビ頭の2小節を放つ ──> 語尾直後に1拍の無音キルスイッチ＋生々しい息継ぎ「スッ……」 |

## 4. サビ頭（兼・冒頭ワンフレーズ）の歌詞・譜割り4案

2小節目の末尾にタイトル『キセグライザー！』を配置し、その語尾の声をそのままスライスして直後の**ボーカルチョップ・イントロ**へ繋げる設計です。

| パターン | 冒頭2小節（サビ予告ワンフレーズ） | 続く3〜4小節目（本編サビでの展開） | 特徴・中毒性のポイント |
| :--- | :--- | :--- | :--- |
| **案A：王道かっこえも引力型** | **偶然じゃない　引き寄せ合って！**<br>**君と私の　キセグライザー！** | ゼロ距離以上の　この繋がりで<br>銀河いちばん　輝けるもん！ | 「偶然じゃない奇跡（アポフェニア）」と「引き寄せ合う引力（アトラクター）」が自然な言葉で入り、1サビのエモさにもラスサビの大号泣にもハマる王道案 |
| **案B：あざと強気・無敵型** | **君がいるから　無敵になれる！**<br>（または *すきぴのせいで　無敵になれる！*）<br>**心ごとぜんぶ　キセグライザー！** | 出会えた奇跡も　この引力も<br>一生わたしと　繋がっててよ！ | 湿っぽさゼロで「君（すきぴ）のおかげで無敵になれた！」という明るく強気なアイドル感が全開になる、現場で一番コールしやすい案 |
| **案C：音ハメ・スタッター中毒型** | **き、き、奇跡が　重なり合って！**<br>**目と目が合えば　キセグライザー！** | 君がくれた「すき」　あの日の歌が<br>私をここまで　連れてきたんだ！ | サビ頭の「き、き、奇跡が」の16分音符連打が直後のボーカルチョップとリンクし、[『メズマライザー』](https://www.youtube.com/watch?v=Twql3i6jnMc) のようなリズム中毒性を生む案 |
| **案D：タイトル第一声・直撃型** | **キセグライザー！　引き合うココロ**<br>**君のおかげで　ここまで来れた！** | 誰にも切れない　重力の中<br>最強の音を　鳴らしてあげる！ | 再生した0秒の第一声にタイトル『キセグライザー！』を叩き込み、2小節目で「君のおかげ」をストレートに伝えるインパクト特化案 |

### BPM 175でのリズム・音ハメ設計（コード：`Dmaj7` ──> `E`）
* **1小節目（`Dmaj7`）**：「ぐうぜんじゃない（タタタタタタ・）」＋「ひきよせあって！（タタタタタタ・）」と8分・16分音符で軽快に跳ねる。
* **2小節目（`E`）**：「きみとわたしの（タタタタタタ・）」に続けて、3拍目裏〜4拍目で**「キ・セ・グ・ラ・イ・ザー！」**とアタック強く言い切る。
* **イントロへの接続**：「ザー！」の直後に1拍の無音キルスイッチ（「スッ」というブレス）を入れ、次小節の頭で平均 -7 LUFS の爆太キック＆「キ・セ・グ・ラ・イ・ザー」のボーカルチョップを一斉に着火させる。

## 5. 制作進行ステップ（サツキ流『メズマライザー』方式）

[『メズマライザー』解説動画](https://www.youtube.com/watch?v=Twql3i6jnMc) の制作順序に倣い、フル尺の歌詞は最後に研ぎ澄ますフローで進めます。

1. **ステップ1：タイトルとテーマの確定【完了】**
   - タイトル：『キセグライザー』（KISEGRAIZER）
   - テーマ：「ふたつの繋がり（目の前のファンとの繋がり ＆ これまでの奇跡とファンとの繋がり）」
2. **ステップ2：サビ頭フックの選定 ＆ 頭からトラック（オケ）を組む【現在地】**
   - 上記4案からサビ頭（冒頭ワンフレーズ）の言葉を決め、DAW（BPM 175 / Key F#m）で「01. サビワンフレーズ ──> 02. ボーカルチョップ・イントロ ──> 03. 1Aメロ引き算ビート」から順に打ち込む。
3. **ステップ3：完成したトラックに歌メロ（譜割り）を乗せる**
   - トラックのキメやグルーヴに100%吸い付くメロディとリズム（何文字で韻を踏むか）を先に確定させる。
4. **ステップ4：最後に「心にとどめを刺す歌詞」を書き上げる**
   - 音とメロディで耳を奪った上で、Aメロ・Bメロ・2Aラップ・落ちサビ・ラスサビの歌詞を徹底的に磨き上げる。
